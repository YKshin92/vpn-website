# 이음 VPN 웹 디자인 프로토타입

한국어 기간권 선택 → 데모 결제 → Outline 이용권 확인 흐름. 브랜드명과 가격은 가안입니다.

현재는 정적 프런트엔드이며 로그인, 실제 결제, Outline 서버 연동, 자동 발급, 데이터 저장을 구현하지 않았습니다. 이메일은 서버로 전송하거나 저장하지 않습니다. 모든 키는 무효한 데모 문자열입니다.

출시 전: 브랜드/가격/기기·트래픽 정책 확정, 사업자 정보와 약관 작성, 중국에서 홈페이지 접근성 검증, 결제업체의 VPN 판매 허용 여부 확인, 서버 측 결제 검증 및 중복 지급 방지, 인증·고객별 동적 키 보호, Outline 발급/회수와 만료 처리, 환불 처리 연결이 필요합니다.
