## GitHub Pages와 로컬 관리자

GitHub Pages는 정적 홈페이지 미리보기다. 백엔드 API·PostgreSQL·AWS/Outline 자격증명은 GitHub Pages에서 실행하지 않는다. 실제 관리자 주소는 `http://127.0.0.1:3000/admin`, 키 관리는 `/admin/keys?server=vpnServer001`이다.

Pages 워크플로는 Node 24에서 npm ci→TypeScript 빌드→단위/컨트롤러 테스트→스크립트 문법 점검 후 홈페이지 허용 목록만 `.pages-preview`로 패키징한다. `/admin`·실제 관리자 HTML/JS/CSS와 키 관리자 파일은 공개 웹 아티팩트에서 제외한다. 이들 소스는 저장소에 포함된다. 기존 홈페이지의 가상 고객/이용권 UI와 로컬 관리자 안내는 유지한다.

`tools/package-public-site.mjs`는 새 폴더에만 패키징해 이전 실행의 파일이 섞이는 것을 막는다. 일반 페이지/스타일/모듈/가상 fixture/폰트·라이선스만 포함한다. 원격 Actions/Pages 실행 결과는 원격 커밋 반영 후 별도로 확인한다.

## 제외·점검

`.env`, AWS 인증 프로필, DPAPI 암호화 파일, 실제 DB, 백업, 로그, node_modules, .build 상태/생성물, 임시 UI 스크린샷, Sites 로컬 실행 자료와 호스팅 연결 설정은 업로드 대상에서 제외한다. `.env.example`은 비밀번호 빈값과 변경 스위치 false인 설정 설명만 포함한다.

AWS/GitHub 토큰·실제 Outline 관리 URL·개인 키 패턴을 파일/행 위치만 출력하는 방식으로 점검했다. TLS 개인 키 파일 1개는 이 프로젝트에서 생성한 가상 로컬 HTTPS 테스트 fixture이며 실제 서비스 인증서가 아니다. 나머지 실제 비밀정보 패턴 검출 없음. 원격 기존 파일과 현재 파일의 차이를 확인하고 원격 main의 기존 트리를 기반으로 커밋한다. 현재 로컬 Sites 체크아웃의 Git 이력을 강제로 재설정하지 않는다.
