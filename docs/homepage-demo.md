# 홈페이지 고객·관리자 데모

2026-10-14. VPN 자동화는 보류하고 기존 홈페이지에 고객/관리자 화면을 연결했다.

- 홈페이지 상단에서 가상 고객을 선택하고 내 이용권에서 상태·만료일·개별 키·주문 내역을 확인한다.
- 신규 고객 체험 상태에서 요금제와 예시 이메일로 데모 주문한다.
- 관리자 데모에서 고객 검색·상태 필터·추가·결제대기 수납 확인·30일 연장을 체험한다.
- 연장은 기존 키를 유지한다. 기간 계산은 가상 기준일 2026-10-14에 고정한다.

데이터는 dist/demo-data.json의 공개 가상 데이터만 사용한다. 개인정보나 실제 비밀을 넣지 않는다. 모든 변경은 브라우저 탭 메모리에만 남고 새로고침하면 초기화된다. 고객 선택은 디자인 체험 기능으로 실제 인증·권한 관리가 아니다. 실제 결제/키 발급/키 회수/DB 저장은 연결하지 않았다. 운영 자원 변경과 재배포도 수행하지 않았다.

로컬 실행: node preview.cjs → http://127.0.0.1:4173

테스트: node --test tests/demo-data.test.mjs tests/portal-model.test.mjs

다음 단계: 화면 검토 후 로그인과 서버 데이터 저장 구현. PG 선정 후 결제 검증을 연결한다.
