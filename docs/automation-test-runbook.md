# 운영 자동화 테스트

> 2026-10-16 변경: 아래의 실제 테스트 순서는 과거 계획이며 실행 승인이 아니다. 최신 목표는 신규 IP 연결·DNS 갱신 후 새 IP 유지이다. 기존 IP 자동 원복은 정상 완료 조건에서 제외한다. 현재 가상 화면과 테스트 코드는 이전 원복 흐름을 유지하고 있으며 수정 대기 중이다. 실제 AWS·DNS 변경은 새 계획에 대한 최종 승인 후 진행한다. 최신 기준은 [개발 설명서](개발설명서_초안.md)와 [작업 현황](작업현황.md)을 따른다.

2026-10-14. 사용자 확인: Lightsail에 Outline 설치 완료, ieumvpn.link 도메인 연결 완료, Outline Manager에서 호스트 이름 변경으로 도메인 기반 키 생성 해결. 실제 AWS/API 조회로 검증한 결과는 아니다.

## 로컬 가상 테스트

`node --test tests/demo-data.test.mjs tests/portal-model.test.mjs tests/trial.test.mjs tests/ip-rotation-simulation.test.mjs`

`node tools/ip-rotation-simulation.mjs`

시뮬레이터는 외부 호출 없이 정상 교체·할당 실패·연결 실패·DNS 실패·검증 실패·복구 실패를 재현한다. 기존 IP는 반환하지 않고 보존한다. 실제 AWS operation 대기, API 타임아웃 조정, 프로세스 재시작·영속 잠금은 아직 구현하지 않았다. 동시 실행 방지는 동일 프로세스의 동일 simulation 객체에만 적용된다. 중국 접속 성공을 검증하지 않는다.

## 실제 테스트 순서

1. 읽기 전용 확인: 서울 인스턴스명·계정·고정 IP·Route 53 hosted zone·A/AAAA/CNAME·TTL·Outline 버전·포트·도메인 기반 키 확인
2. 관리자 수동 테스트 승인 범위: 신규 고정 IP 1개 할당, 기존 IP 분리·새 IP 연결, ieumvpn.link의 해당 A 레코드 변경, 연결 검사, 실패 시 원복. 기존 IP 반환은 초기 테스트에서 제외
3. 서버 연결 완료와 DNS 전파를 확인하고 기존 앱·동일 키로 재연결 검사
4. 별도 승인된 전용 테스트 키만 생성·이름 변경·제한·회수 테스트. 기존 사용자 키는 제외
5. 고객 가상 주문·무료체험·연장 테스트와 실제 서버 키 권한을 연결하기 전 별도 시험 데이터/DB 준비

필요한 정보: 인스턴스명, 요금제, 현재 사용자 여부, AWS 접속 방법, Route 53 호스팅 영역, VPN 접속 포트. API 비밀 주소나 AWS 키를 공개 채팅·소스·GitHub에 저장하지 않는다.

현재 AWS CLI와 자격증명은 이 작업 환경에서 확인하지 못했다. 서버·DNS 변경은 실행하지 않았다. 가상 서버의 리전은 요구사항에 맞춰 서울로 변경했고 가상 주소는 example.test와 문서 예시 IP를 유지했다.
