## 첫 진입 자동 조회 수정

2026-10-17 사용자 승인으로 서버관리 탭의 최초 자동 조회를 수정했다. 기존 코드는 tbody의 자식 수를 조회 여부로 판단해 초기 안내 행 또는 이력 조회가 만든 빈 상태 행이 있으면 AWS·DNS 조회를 건너뛰었다.

이제 fleetLoaded/fleetLoading 상태로 판단한다. 첫 진입은 실제 인프라 조회와 작업 이력 조회를 시작하고, 인프라 조회가 진행 중이면 중복 요청을 보내지 않는다. 정상 조회 후 재진입은 기존 결과를 사용하며 전체 새로고침으로 갱신할 수 있다. HTTP 실패나 부분 조회는 정상 완료로 고정하지 않아 다음 진입에서 다시 조회한다. 로그아웃은 완료/진행 상태를 초기화하며 이전 요청의 응답은 순서 번호로 무효화한다.

회귀 검사: 안내 행이 있어도 첫 조회 실행·빠른 재진입 중복 차단·정상 결과 재사용·실패 후 재진입 재시도·로그아웃 초기화를 실제 컨트롤러와 가짜 응답으로 확인했다. 기본 45개 통과·JS 문법·실행 중 HTTP 스크립트 반영 확인. 브라우저 시각/실제 클릭 검사는 기존 도구 제한으로 미실행이다. 수정은 dist/admin.js·tests/admin-server-ui.test.mjs·문서이며 AWS 변경·DB 변경·GitHub 반영·백엔드 재시작은 없다.

## 전체 관리자 배치·밀도 후속 조정

사용자의 전체 화면 배치·정보 밀도 정리 요청으로 고객관리·서버관리·고객 우측 패널·IP 교체 창을 코드 기준으로 함께 검토했다. 기존 브라우저 도구 접근 제한으로 시각 검사는 수행하지 않았다.

- 고객·서버 모두 최대 1480px 공통 본문 폭과 헤더 정렬을 사용해 메뉴 이동 시 폭 차이를 줄였다. 상단 여백·제목·메뉴 높이를 낮추고 요약 카드의 테두리·숫자 크기·간격을 통일했다.
- 고객 표는 시작·만료를 한국 시간 날짜만 표시한다. 상세 패널의 정확한 시각과 저장 데이터는 유지한다. 이메일·키 ID는 줄바꿈하고 날짜·숫자는 비교하기 쉽게 정렬한다. 표 제목은 짧게, 기존 정보는 그대로 유지한다.
- 표 행·검색·필터·페이지 이동의 간격을 줄이고 고객 표 헤더는 표 내부 스크롤 시 고정한다. 매출 금액·건수와 결제/환불 금액은 오른쪽 정렬한다.
- 고객 패널은 넓은 화면에서 기본 정보 라벨·값을 두 묶음으로 배치하고 좁은 화면에서는 한 묶음으로 전환한다. 제목·닫기 고정, 별도 스크롤, 모바일 전체 너비와 Noto Sans KR을 유지한다.
- 모바일에서는 요약 2열·폼 1열을 유지하며 주요 검색/메뉴 버튼은 44px 높이, 표 작업 버튼은 40px 이상으로 확보한다.

수정 파일은 dist/admin.html·admin.js·admin.css다. 기본 테스트 43개·JS 문법·HTML 구조·CSS 중괄호 검사 통과. 실제 HTTP 관리자 200 및 최신 CSS·날짜 전용 표시 코드·폰트 링크 확인. 운영 데이터·API 계약·DB·AWS·GitHub 변경이나 백엔드 재시작은 없다. 다음은 사용자 화면 확인에 따른 미세 조정이다.

## 승인 범위

서버 관리자 관점의 목록·상세 패널·IP 교체 작업 창·개발 도구 분리 제안에 사용자 ‘그렇게 진행해줘’로 승인했다. 진행 중 홈페이지 전체 Noto Sans KR 적용을 추가 요청했다. 이번 작업은 UI·폰트·로컬 제공 경로 및 검증 범위이며 실제 IP·DNS 변경을 실행하지 않았다.

## 화면 구조

- 고객관리 / 서버관리 상위 두 메뉴를 유지한다.
- 서버관리는 전체 서버·확인 필요·진행 중 작업 요약, 검색·필터, 서버 표로 시작한다. 작업 목록 미조회 시 진행 건수는 미확인 기호로 표시한다.
- 표는 서버/도메인·서버 실행 상태·서비스 실시간 점검·DNS 비교·IP·조회 시각·상세 버튼으로 구성한다. 확인 필요 서버를 우선 정렬한다.
- 선택한 서버의 우측 상세 패널에서 개요·변경 이력·설정을 확인한다. 좁은 화면은 목록 아래에 상세를 배치하고 표는 가로 스크롤한다.
- 이력은 현재 API가 반환하는 전체 최대 30건 중 선택 서버 기록으로 제한됨을 표시한다. 다른 서버의 이력이나 계획을 선택 서버의 작업으로 실행할 수 없도록 대상을 대조한다.
- IP 교체는 기본 화면과 분리된 native dialog에서 진행한다. 사전 확인·계획 검토·실행·결과 확인 흐름, 실제 실행 게이트, 계획 준비/취소, 기존 승인 확인 항목을 유지한다.
- 작업 상태 조회는 읽기 전용이다. 작업 창에서 실행 중 기록을 주기적으로 조회해 단계 진행·확인 대기를 표시한다. 실행 요청을 자동 반복하지 않는다. 실행 중 대상 변경·닫기·로그아웃을 제한한다.
- 모의 작업과 과거 가상 시험은 개발·시험 도구의 접힌 영역에 모은다.

## 상태 표시의 의미

AWS 인스턴스 실행·공개 DNS 비교·서비스 연결을 구분한다. 현재 인프라 조회 API에는 서비스 포트 실시간 점검이 없어 표에는 ‘미점검’, 상세에는 ‘미연동’으로 표시한다. 최근 성공 작업의 포트는 과거 작업 정보라고 명시한다. 고객 수·사용량도 미연동이다. DNS 일치를 중국 접속 가능으로 표시하지 않는다.

DNS 단계가 불확실하면 이미 적용됐거나 전파 중일 수 있으므로 실제 상태 대조를 안내한다. 아직 backend가 전파 대기를 독립 상태로 반환하지 않기 때문에 단순히 ‘전파 중’으로 확정하거나 성공으로 바꾸지 않는다.

기존 실제 실행 API는 보관 정책과 ackRetainOldIp를 요구한다. 이번 UI 개편은 이 계약을 변경하지 않는다. 검증 후 반환을 기본 선택으로 만드는 기능은 아직 미구현이며, 현재 작업 창에 보관 정책과 별도 반환 정리 경계를 표시한다. 이전 실제 시험의 추가 승인 반환 결과는 이력에서 확인할 수 있다.

## Noto Sans KR

홈페이지·관리자·버튼·입력·선택·텍스트 입력 영역에 동일한 Noto Sans KR을 적용했다. Google Fonts 공식 저장소의 가변 TTF를 받아 글리프 삭제 없이 WOFF2로 변환했다. 100–900 굵기 축·한글/라틴/숫자 매핑을 확인했다.

- 공개 파일: dist/fonts/NotoSansKR-Variable.woff2, 3,907,916바이트
- 공통 CSS: dist/fonts.css / font-display: swap
- 출처·라이선스: dist/fonts/README.md·OFL.txt
- 관리자: 허용 목록에 폰트/CSS 경로만 추가하고 CSP font-src 'self' 적용
- 홈페이지: 상대 경로로 GitHub Pages의 하위 경로 이관도 고려
- 실행 중 외부 Google Fonts·CDN 요청 없음. 다른 글꼴은 로딩 중 또는 미지원 문자용 대체 글꼴이다.

## 검증과 영향

기본 테스트 43개 통과. 실제 컨트롤러를 DOM 어댑터에서 실행해 서버 검색/필터·이력 대상 분리·실행 중 선택 방지·게이트/대상/만료 검사·불확실한 DNS 진행 표시를 확인했다. HTML ID 중복·스크립트 대상 누락·태그 중첩과 JS 문법을 확인했다. 이 검사는 실제 브라우저 렌더링 검사를 대신하지 않는다.

DB 통합 테스트 43개 중 42개 통과, 기존 최초 관리자 보존 1개 생략. 추가 검사는 동일 출처 폰트 정책·WOFF2 MIME/헤더·허용 목록 밖 파일 404를 확인한다. 기존 사용자 계정·DB 스키마·키·실제 결제는 유지했다.

읽기 전용 관리자를 재시작했고 홈페이지 미리보기도 실행했다. 실제 HTTP로 두 페이지·공통 CSS·WOFF2 모두 200, font/woff2·파일 바이트 수 일치 확인. 인증된 관리자 목록에서 실제 변경 enabled=false·기존 성공 작업 상태 보존을 확인했다. 검사 계정/세션 제거. 실제 브라우저 시각 검사는 기존 도구 접근 정책 제한으로 미실행이다.
