# 동업자 공유용 화면 미리보기

- 목적: 고객 여정과 관리자 화면 구성을 함께 검토한다. 운영 서비스 배포나 공개 가입 활성화가 아니다.
- 최신 화면의 정적 스냅샷을 `partner-preview/`에 별도로 게시한다. 기존 백엔드/운영 데이터/로컬 비밀정보는 이 게시물에 포함하지 않는다.
- 상단 메뉴: 홈페이지, 회원가입, 로그인, 내 이용권, 고객관리, 서버관리, 키 관리, 고객·키 연결.
- 관리자 로그인 절차 없이 예시 관리 화면을 볼 수 있다. 이는 정적 공유 화면이며 관리자 접근 권한을 부여하는 기능이 아니다.
- 데이터는 별도 합성 DB/수작업 예시만 사용한다. 고객 이메일은 `example.test`, IP는 문서용 주소다. Outline 접속 키는 무효한 예시 문자열만 표시한다.
- 발송/결제/저장/삭제/서버/IP 변경 요청은 리뷰 전용 어댑터에서 차단한다. 실제 API로 전달하지 않는다. 로그인·로그아웃은 페이지 상태 이동만 표현한다.
- 실제 정보나 비밀번호를 입력하지 말라는 안내를 모든 화면 상단에 표시한다. 공개 GitHub Pages이므로 링크를 아는 누구나 예시 화면을 열 수 있다.
- 폰트는 기존 Noto Sans KR 파일과 라이선스를 유지한다. GitHub Pages 하위 경로 링크와 정적 의존성을 검사한다.
- 변경 범위: 공유 아티팩트, Pages 워크플로, 검증 도구/문서. 현재 로컬 실제 기능과 운영 설정은 바꾸지 않는다.

## 이후 실제 운영 배포

별도 서버, HTTPS, 운영 DB·백업, 서버 측 관리자/고객 인증, 실제 PG·SES·Outline 연결과 권한을 별도로 준비해야 한다. 이 미리보기 아티팩트나 리뷰 어댑터를 운영 인증/결제 서버에 사용하지 않는다.
